# GARCD Root-cause owner protocol

Categories: ROOT_INDEPENDENT / SAME_ROOT_SIBLING / LIKELY_CASCADE / BLOCKED_UNCERTAIN / INFRASTRUCTURE.

Owner must provide root cause, affected declarations, minimal patch, direct build command and complete error log.
No unverified patch should be merged solely on AI consensus.
Source hash, first error, full error count and checked-in commit govern whether a patch is promoted.
Never introduce sorry/axiom/admit to fake proof closure.
